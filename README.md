# A Birthday Surprise for Ashi

A small, responsive static birthday website made by Farid Khan for Aashima (Ashi).

## Preview locally
Open `index.html` in your browser. The page uses Google Fonts when an internet connection is available; the rest of the site is self-contained.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `birthday-for-ashi`).
2. Upload `index.html` and this `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait a minute or two. Your site will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

The envelope card is interactive: tap or click it to unfold the birthday letter.

The `assets/ashi.jpg` file is the photo displayed on the page. Keep the `assets` folder in the same repository as `index.html`.
